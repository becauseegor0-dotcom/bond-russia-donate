# BOND RUSSIA DONATE

Онлайн-портал заявок на пополнение BOND RUB. Оплата и выдача валюты выполняются вручную.

## Render deployment

1. Создайте PostgreSQL database в Render и скопируйте Internal Database URL.
2. Загрузите этот проект в свой GitHub-репозиторий.
3. В Render создайте **Web Service** из репозитория.
4. Build Command: `npm install`
5. Start Command: `npm start`
6. Добавьте Environment Variables:
   - `NODE_ENV` = `production`
   - `DATABASE_URL` = Internal Database URL из Render PostgreSQL
   - `PGSSL` = `true`
   - `SESSION_SECRET` = длинная случайная строка (не менее 32 случайных символов)
   - `ADMIN_PASSWORD_HASH` = bcrypt-хеш нового пароля администратора
7. После деплоя откройте `/health` — ожидается `{"ok":true,...}`.

## Создание bcrypt-хеша пароля

На компьютере с Node.js выполните в папке проекта:

```bash
node -e "require('bcryptjs').hash('ВСТАВЬТЕ_НОВЫЙ_ПАРОЛЬ_ЗДЕСЬ',12).then(console.log)"
```

Скопируйте полученный хеш в `ADMIN_PASSWORD_HASH` в Render. Не используйте пароль, который уже отправляли в переписке. Не публикуйте хеш или пароль в GitHub.

## Важно

- Render free web services могут засыпать при простое; первый запрос после простоя может загружаться медленно.
- Для постоянного хранения заявок нужна PostgreSQL. Не используйте локальный SQLite/файлы на бесплатном диске сервиса.
- Перед публичным запуском настройте резервные копии базы данных и проверьте правила игры/платёжного провайдера.
- Это не принимает платежи и не выдаёт игровую валюту автоматически.
- В текущей версии предусмотрен статус заявки по номеру. Считайте номер заявки секретом и не публикуйте его.
